> **口径**：A4 普通纸（非预印套打）、金额两位小数、借贷必平；企业会计准则与小企业会计准则双准则。

**判定依据（与国内主流产品一致）**：

1. 金蝶 KIS/K3、用友 T3/T+ 的凭证录入：选科目后**方向由科目余额方向决定**（资产/成本/费用默认借，负债/权益/收入默认贷），可手改；改后给出"与科目方向相反"的视觉提示但**不阻止保存**——红字冲销、备抵科目、汇兑损益等业务确实需要反向记账。
2. 科目选择**编码优先**：输入 `1001` 直接筛选定位，名称次之。凭证录入是高频操作，"逐级展开树"不成立。
3. 打印版式以财政部报表格式为骨架、金蝶/用友为事实标准：凭证竖版 A4 一页、资产负债表左右分栏带"行次/期末余额/年初余额"、利润表"本期/上期/本年累计/上年累计"、现金流量表"本期/上期 + 补充资料"。

### 1.3 还需补齐的三项（建议本轮一并改）

**① 方向列显示"科目天然方向"与"异向"提示**

现状方向列只有借/贷两态（`VoucherEdit.tsx:456-470`），用户看不出"这笔是不是记反了"。规范做法：

```tsx
// 方向单元格：Segmented + 科目方向提示
const naturalSide = accountOf(r)?.balanceSide;           // 来自 useAccounts.byId
const isOpposite = naturalSide && r.direction !== naturalSide;

<div className={isOpposite ? 'dir-cell dir-opposite' : 'dir-cell'}>
  <Segmented
    size="small" block value={r.direction}
    options={[{ label: '借', value: 'debit' }, { label: '贷', value: 'credit' }]}
    onChange={(v) => updateRow(r.key, { direction: v as Direction, directionTouched: true })}
  />
  {naturalSide && (
    <Tooltip title={isOpposite ? '与科目余额方向相反：仅红字冲销、备抵、汇兑损益等场景使用' : '科目余额方向'}>
      <span className={isOpposite ? 'dir-hint dir-hint-warn' : 'dir-hint'}>
        科目方向：{naturalSide === 'debit' ? '借' : '贷'}
        {isOpposite && ' ⚠'}
      </span>
    </Tooltip>
  )}
</div>
```

```css
.dir-cell { display: flex; flex-direction: column; gap: 2px; }
.dir-hint { font-size: 11px; color: rgba(0,0,0,.45); line-height: 1; }
.dir-hint-warn { color: #d46b08; }
.dir-opposite { background: #fffbe6; border-radius: 4px; outline: 1px solid #ffe58f; }
```

> 判定"异向"用**当前科目**的 `balanceSide` 即可，不要另存 `naturalSide` 到行状态——科目方向被管理员改动后，界面应跟随最新配置；需要"留痕"的是落库后的凭证（见 ②）。

**② 落库存方向快照，供审计解释**

`voucher_entry` 增加可空列 `natural_side`（`debit|credit`），创建/更新凭证时写入"当时科目的余额方向"：

```prisma
model VoucherEntry {
  // ...
  direction    String  @db.VarChar(10) // debit|credit（实际记账方向）
  naturalSide  String? @map("natural_side") @db.VarChar(10) // 科目当时的天然方向，用于审计解释
  // ...
}
```

打印/查账时若 `direction !== naturalSide`，可在凭证预览与明细账上加"异向"小标（打印件可不显示，屏幕与审计导出显示）。**不要**用"重算当前科目方向"代替快照，否则科目方向一改，历史凭证的异向解释就变了。

**③ 清空科目时重置 `directionTouched`**

现状 `applyAccount` 在 `accountId == null` 时保留 `directionTouched`（`VoucherEdit.tsx:193-214`）。用户若先手改方向、再清空科目、再选新科目，方向不会跟随新科目。规范：

```ts
if (!account) {
  next.directionTouched = false;   // 清空科目 = 放弃此前的手工方向
  next.direction = 'debit';        // 回到新行默认值
}
```

### 1.4 为什么允许异向（不要在前端拦截）

| 合法场景 | 例 | 方向表现 |
|---|---|---|
| 红字冲销 | 冲销已记账收入 | 借 主营业务收入（与收入天然贷方相反） |
| 备抵科目 | 计提坏账准备 | 借 信用减值损失 / 贷 坏账准备（坏账准备天然贷方，正常） |
| 资产减值 | 固定资产减值 | 借 资产减值损失 / 贷 固定资产减值准备 |
| 汇兑损益 | 外币账户期末调汇 | 财务费用可借可贷 |
| 冲回暂估 | 冲回上月暂估成本 | 借 应付账款（负债天然贷方，异向） |

所以前端只提示、不拦截；拦截放在"借贷必平 + 科目为明细 + 现金流量项目齐全"这三条硬规则上（后端 `vouchers.service.ts:378-479` 已实现）。

### 2.2 建议补的两点

**① 排序：完全匹配 > 编码前缀 > 名称包含**

现状 `filterOption` 只做"是否命中"，候选顺序沿用接口的 `code asc`。输入 `1001` 时"1001 库存现金"通常排第一，但输入 `100` 时 `1001/1002/1012` 混排，用户仍要扫。规范：命中后按分值排序（不改接口，前端对 `options` 做一次 `useMemo` 排序）：

```ts
export function scoreAccount(a: { code: string; name: string }, q: string): number {
  const s = q.trim();
  if (!s) return 0;
  if (a.code === s) return 100;
  if (a.code.startsWith(s)) return 80;
  if (a.name === s) return 60;
  if (a.name.includes(s)) return 40;
  if (a.code.includes(s)) return 30;
  return -1;
}
```

**② 规模：科目 >500 条时改服务端搜索（可选）**

一套标准企业科目表约 150~250 条，小企业 <100 条，本地过滤足够。只有当客户自建大量明细（>500）时才需要：

```ts
// GET /accounts/search?bookId=1&q=1001&leafOnly=true&limit=20
@Get('search')
search(@Query() q: SearchAccountDto) {
  return this.prisma.account.findMany({
    where: {
      bookId: q.bookId,
      isActive: true,
      ...(q.leafOnly ? { isLeaf: true } : {}),
      ...(q.q ? { OR: [{ code: { startsWith: q.q } }, { name: { contains: q.q } }] } : {}),
    },
    orderBy: { code: 'asc' },
    take: q.limit ?? 20,
    select: { id: true, code: true, name: true, balanceSide: true, isLeaf: true, auxFlags: true },
  });
}
```

> `code startsWith` 命中 `@@unique([bookId, code])` 索引前缀；不要一上来就 `contains`（全表扫描）。

**金额大写算法**（已验证 29 组用例，含 `0.05`、`1005.00`、`1,002,003.00`、`100,010,001.00`、`999,999,999,999.99`）：

```ts
const DIGITS = ['零','壹','贰','叁','肆','伍','陆','柒','捌','玖'];
const SMALL_UNITS = ['仟','佰','拾',''];
const GROUP_UNITS = ['','万','亿'];

function sectionToChinese(n: number): string {
  let out = '';
  let pendingZero = false;
  for (let slot = 0; slot < 4; slot++) {
    const digit = Math.floor(n / 10 ** (3 - slot)) % 10;
    if (digit === 0) { if (out) pendingZero = true; }
    else {
      if (pendingZero) { out += '零'; pendingZero = false; }
      out += DIGITS[digit] + SMALL_UNITS[slot];
    }
  }
  return out;
}

function integerToChinese(n: number): string {
  if (n === 0) return '零';
  const groups: { value: number; index: number }[] = [];
  let rest = n;
  for (let i = 0; rest > 0; i++, rest = Math.floor(rest / 10000)) {
    const g = rest % 10000;
    if (g > 0) groups.push({ value: g, index: i });
  }
  let out = '';
  for (let k = groups.length - 1; k >= 0; k--) {
    const { value, index } = groups[k];
    if (k < groups.length - 1) {
      const lowerIndex = groups[k + 1].index;
      if (index - lowerIndex > 1 || value < 1000) out += '零';
    }
    out += sectionToChinese(value) + GROUP_UNITS[index];
  }
  return out;

/** 入参：分 */
export function amountInChinese(cents: number): string {
  const neg = cents < 0;
  const abs = Math.abs(Math.trunc(cents));
  if (abs === 0) return '零元整';
  const yuan = Math.floor(abs / 100);
  const jiao = Math.floor((abs % 100) / 10);
  const fen = abs % 10;
  let out = '';
  if (yuan > 0) out += integerToChinese(yuan) + '元';
  if (jiao === 0 && fen === 0) out += '整';
  else if (jiao > 0) {
    if (yuan === 0) out += '零元';
    out += DIGITS[jiao] + '角' + (fen > 0 ? DIGITS[fen] + '分' : '整');
  } else {
    if (yuan === 0) out += '零元';
    out += '零' + DIGITS[fen] + '分';
  }
  return (neg ? '负' : '') + out;
}
```

**整数分汇总（借贷必平的正确判法）**：

```ts
export function toCents(v: string | number): number {
  if (typeof v === 'number') return Number.isFinite(v) ? Math.round(v * 100) : 0;
  const s = String(v).trim();
  if (!s) return 0;
  const neg = s.startsWith('-');
  const m = /^(\d+)(?:\.(\d{0,2}))?$/.exec(neg ? s.slice(1) : s);
  if (!m) return 0;
  const cents = Number(m[1]) * 100 + Number((m[2] ?? '').padEnd(2, '0'));
  return neg ? -cents : cents;
}

// 借贷平衡判定
const balanced = debitCents === creditCents && debitCents > 0;
```
